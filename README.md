# 我的​​小宇宙 · My Little Universe

一个简约、温柔、适合记录日常与心情的个人网站。

## 功能
- 今日心情打卡与本地保存
- 日常碎片新增与爱心互动
- 随机抽取今日灵感
- 留言互动（当前仅保存在打开页面的会话中）
- 手机端自适应布局

## 发布到 GitHub Pages
仓库已包含 Pages 工作流：推送到 `main` 后会自动尝试部署。
首次使用时，请到仓库 **Settings → Pages**，将 **Build and deployment → Source** 设为 **GitHub Actions**。部署完成后，网站地址通常为：

`https://kesideyu868-hub.github.io/my-personal-website/`

## 个性化
打开 `index.html`，可以修改「关于我」的介绍、文字、表情和配色。
心情记录使用浏览器本地存储；不会自动同步到其他设备。
